勉強会のメッセージの送信予約作業を手伝ってください

勉強会の前後に合計4回 connpass からメッセージを送信予約します。

| # | メッセージ | 送信予約日時 |
|---|---|---|
| 1 | 配信URLの案内 | 前日 18:00 |
| 2 | 配信URLの案内 | 当日 17:30 |
| 3 | アンケート依頼 | 当日 21:00 |
| 4 | アンケート依頼（リマインダー） | 翌日 11:30 |

## 操作手順

現在開いているイベントページから、以下の手順を4通分それぞれ繰り返してください。

1. ページ上部の「メッセージを送る」をクリック
2. 宛先：「補欠者」のチェックを外す（「共同管理者」「発表者」「参加者」はチェックしたまま）
3. 件名：文面セクションに記載の件名を入力する
4. 本文：文面セクションのコードブロック内をコピーして貼り付ける
5. 送信予約日時：開催日から算出した日時を入力する。日付は `2026/09/09` 形式、時間は `18:00` 形式でテキスト入力できる（カレンダーUIを操作しなくてよい）
6. 押す前に、送信予約日時の**日付と時間の両方**が入力され、かつ**未来の日時**であることを画面上で確認する
7. 「即時送信/予約」ボタンを押す。6が確認できていれば**依頼者への都度確認は不要**（後述の仕様を参照）
8. 予約タブに遷移するので、次のメッセージを作成するために新規メッセージ画面に戻る

※ 参考：https://help.connpass.com/organizers/bulk-message

### 「即時送信/予約」ボタンは日時が入っていれば予約になる

ボタン名に「即時送信」と入っていますが、**送信予約日時が入力されていれば予約として登録され、その場では送信されません**。画面にも「※送信予約日時が設定されていない場合、即時送信されます」と注記があるとおり、即時送信されるのは**日時が空欄のときだけ**です。

そのため、手順6の確認さえ取れていれば、作業者は依頼者に確認せずボタンを押して構いません。逆に日付・時間のどちらかでも空欄なら、押した瞬間に参加者全員へ即時送信されるので、必ず両方の入力を確認してください。

### 予約は後から取り消せる

予約タブから該当メッセージを開くと（URL: `https://connpass.com/event/{{connpassイベントID}}/message/reserved/{{メッセージID}}/`）、末尾に「**下書きに戻す**」ボタンがあります。注記は「※メッセージを編集したい場合は、下書きに戻してから編集してください。」

つまり予約は不可逆な操作ではありません。日時や本文を間違えて予約してしまっても、**送信予定時刻より前であれば下書きに戻して修正し、予約し直せます**。この取り消し手段があることも、予約ボタンを都度確認なしで押してよい根拠のひとつです。

### 作業メモ（コーディングエージェント向け）

- 新規メッセージ画面へは `https://connpass.com/event/{{connpassイベントID}}/message/new/` に直接遷移するのが速い。1通ごとにこのURLへ戻れば入力欄がクリアされた状態から始められる
- ページ遷移すると要素の参照IDは無効になる。1通ごとに要素を取得し直すこと
- 「補欠者」のチェックは**クリックで外す**。フォーム値の直接指定はチェックボックスだと失敗することがある
- 日付欄に値を入れるとカレンダーがポップアップするが、「即時送信/予約」ボタンには重ならないのでそのまま押せる
- 送信予約に成功すると「メッセージ送信を予約しました。」と表示され、予約タブに遷移する

### 4通の予約後に確認すること

- [ ] 予約タブに4件並び、送信予約日が「前日18:00 / 当日17:30 / 当日21:00 / 翌日11:30」になっている
- [ ] 予約メッセージの詳細画面を開き、宛先が「共同管理者・発表者・参加者」の3つで、**補欠者が含まれていない**
- [ ] 本文中の `{{回数}}` `{{connpassイベントID}}` `{{アンケート回答期限}}` がすべて置換済み

## テンプレート変数

現在開いているイベントページから以下の値を確認してください：

- `{{回数}}` … イベントタイトルに含まれる回数（例: 119）
- `{{connpassイベントID}}` … イベントURLに含まれるID（例: `event/374561/` の `374561`）
- `{{開催日}}` … イベントの開催日（例: 2024/12/12）

以下の値は自動で導出してください：

- `{{アンケート回答期限}}` … 開催日の次の月曜日（例: 開催日が12/12（木）なら `12/16（月）`）
